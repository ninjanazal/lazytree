internal/graph: the core algorithm ^p2x0061

Layout(commits): one pass, children before parents ^p2x0063

1. Own lane: reuse laneOf[hash] if a child reserved it, else
lowest free lane ^p2x0065

2. Parent lanes: first parent inherits this lane (mainline
stays straight); merge parents get a fresh lane; an already-
laned parent keeps its lane (convergence) ^p2x0067

3. Free the lane if no parent inherited it (root, or branch
tip collapsing into an active lane) ^p2x0069

4. Emit GraphNode{Lane, Parents, Color = lane % palette};
track max width.
Free lanes kept sorted → low lanes reused → narrow graph ^p2x0071

RenderCommitLine(node, next, activeLanes, width) ^p2x0073

Row 1: │ for active lanes, ● in the commit's lane
Row 2 (only when a parent lane ≠ own lane): arcs ╰─╮ / ╭─╯
activeLanes mutated in place for the next row ^p2x0075

# Excalidraw Data

## Text Elements
✅ Design Choices ^p4x0001

Each decision: what · why · trade-off · when to revisit ^p4x0002

↩ Overview ^p4x0004

← 03 Runtime & Message Flow ^p4x0006

→ 05 Missing & Risks ^p4x0008

1. Graph decoupled from the TUI ^p4x0010

What: graph imports only model types, returns lanes +
strings ^p4x0012

Why: Lane algorithm is the most bug-prone part →
pure, row-by-row testable ^p4x0014

Trade-off: Rendering still uses lipgloss → ANSI in
output complicates width math/tests ^p4x0016

Revisit: Return glyph + color index; UI applies color ^p4x0018

2. Shell out to git CLI (no go-git) ^p4x0020

What: Every op is exec git via Runner.Run ^p4x0022

Why: Exact git behavior (config, mailmap, commit-
graph, partial clones, credentials); no big dep; fast
on huge repos ^p4x0024

Trade-off: Process per call; text parsing; git must
be installed ^p4x0026

Revisit: Only if call overhead shows in profiles →
batch / cat-file --batch first ^p4x0028

3. NUL/SOH git log format ^p4x0030

What: %x00 between records, \x01 between fields, body
last ^p4x0032

Why: Bodies contain newlines, tabs, |; NUL/SOH never
appear ^p4x0034

Trade-off: Cryptic format string: keep documented
next to ParseLog ^p4x0036

4. Async paging (500/page) ^p4x0038

What: Show page 0 fast, load the rest with --skip ^p4x0040

Why: Time-to-first-paint on linux/chromium-size repos ^p4x0042

Trade-off: --skip re-walks history; full re-layout
per page → O(n²) ^p4x0044

Revisit: One streaming git log + incremental Layout
(already top-down; save laneOf/free lanes) ^p4x0046

5. Debounced diff (150 ms) ^p4x0048

What: Load diff only after the cursor stops ^p4x0050

Why: Holding j shouldn't spawn hundreds of git show ^p4x0052

Trade-off: Small delay; no cache, revisits reload ^p4x0054

Revisit: Small LRU keyed by hash ^p4x0056

6. Silent live fetch ^p4x0058

What: git fetch --all --quiet every 60s, errors
ignored ^p4x0060

Why: Leave it open, remotes stay current; don't nag
offline ^p4x0062

Trade-off: Credential prompts/SSH agents; invisible
failures; full reload even with no changes; network
without asking ^p4x0064

Revisit: Configurable interval/off, ⚠ on repeated
failure, reload only when refs change ^p4x0066

7. Seq/Gen tokens, not cancellation ^p4x0068

What: Each async chain carries Seq or Gen; stale msgs
dropped ^p4x0070

Why: Bubble Tea cmds can't be cancelled easily;
simple, race-free ^p4x0072

Trade-off: Stale work still runs; git processes still
finish ^p4x0074

Revisit: Cancellable contexts for expensive loads ^p4x0076

8. --all by default ^p4x0078

What: 'a' toggles to HEAD-only ^p4x0080

Why: The product is about topology (gitk --all
mindset) ^p4x0082

Trade-off: Noisy with hundreds of remote branches ^p4x0084

Revisit: Ref filters (hide remotes, globs) ^p4x0086

9. In-memory search ^p4x0088

What: Case-insensitive substring on
subject/hash/author; graph still walked in full ^p4x0090

Why: Instant, no git calls ^p4x0092

Trade-off: Only loaded commits; no body/path/content
search ^p4x0094

Revisit: Deep search: --grep / -S / -- path ^p4x0096

10. Refs by full hash, tags dereferenced ^p4x0098

What: --dereference maps annotated tags to their
commit ^p4x0100

Why: Right row for tag pills; no short-hash
collisions (fixed in dad5e8f) ^p4x0102

11. Diff as centered popup ^p4x0104

What: Enter opens 80% overlay; esc closes ^p4x0106

Why: Log table gets full width for graph + message ^p4x0108

Trade-off: Can't see graph and diff side by side ^p4x0110

Revisit: Optional split view on wide terminals ^p4x0112

12. Zen mode ^p4x0114

What: Animated full-screen graph, decrypting title,
breathing dots ^p4x0116

Why: Personality; a dashboard to leave open with live
fetch ^p4x0118

Trade-off: 120 ms full-graph re-renders; no real
function ^p4x0120

13. Centralized keymap ^p4x0122

What: keys.go holds every key.Binding ^p4x0124

Why: One source for bindings and help ^p4x0126

Trade-off: Footer help is a hard-coded string, not
generated ^p4x0128

Revisit: Generate help from keyMap ^p4x0130

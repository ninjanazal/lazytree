🌿 1. Graph decoupled from the TUI ^pde0017

🎯 internal/graph knows nothing about Bubble Tea.
✅ Layout and rendering are tested as plain functions.
⚖ Renderer returns coloured strings, so colour is not
    fully separated yet. ^pde0018

🧱 2. Shell out to git (no go-git) ^pde0022

🎯 Every operation runs the real git binary.
✅ Exact git behaviour: config, mailmap, worktrees,
    submodules.
⚖ Process start-up cost per call; git must be installed. ^pde0023

🧾 3. NUL / SOH log format ^pde0027

🎯 %x00 between commits, %x01 between fields, body last.
✅ Multi-line commit messages can never break the parser.
⚖ Format string must stay in sync with ParseLog. ^pde0028

⚡ 4. Stream the history ^pde0032

🎯 One long-lived git log, read 500 commits at a time.
✅ First screen in ~14 ms; no O(n²) --skip paging.
⚖ A process to close when a reload supersedes it. ^pde0033

📈 5. Incremental layout ^pde0037

🎯 Layouter keeps its state between pages.
✅ Each page costs O(page); 108k commits in ~1.2 s.
⚖ Commits must arrive newest-first, append-only. ^pde0038

⏱ 6. Debounced, cached diffs ^pde0042

🎯 Load a diff 150 ms after the cursor stops; keep 32 in
    an LRU.
✅ Holding j doesn't spawn a git show per row; going back
    is instant.
⚖ Small delay before the diff appears. ^pde0043

🔄 7. Silent live fetch ^pde0047

🎯 git fetch --all every 60 s; reload only if refs moved.
✅ The view stays current without you doing anything.
⚖ Network use and credential prompts; configurable / off. ^pde0048

🎟 8. Tokens, not cancellation ^pde0052

🎯 Each async chain carries a Seq / Gen; stale messages
    are dropped.
✅ Simple and race-free in the Elm loop.
⚖ Abandoned work still runs to completion (except the log
    stream). ^pde0053

🌐 9. --all by default ^pde0057

🎯 Show every branch, remote and tag; a toggles to HEAD
    only.
✅ Topology is the point of the tool.
⚖ Busy repos look busy: hence t / r / hide_refs. ^pde0058

🔎 10. Jump-style search ^pde0062

🎯 Highlight and jump; never hide rows.
✅ The graph stays intact while you search.
⚖ Non-matching rows still take space. ^pde0063

🧰 11. Two search engines ^pde0067

🎯 Memory for loaded commits; git for g: s: p:.
✅ Instant as-you-type plus whole-history power.
⚖ Two code paths to keep consistent. ^pde0068

🪟 12. Split view on wide terminals ^pde0072

🎯 Diff pane next to the log at ≥ 140 columns.
✅ See history and changes together, no popups.
⚖ Narrower message column. ^pde0073

🎨 13. Adaptive colours ^pde0077

🎯 Every colour has a light and a dark variant.
✅ Readable in both terminal themes.
⚖ Auto-detection can be wrong: theme = light | dark. ^pde0078

🔒 14. Read-only ^pde0082

🎯 No checkout, commit or reset.
✅ Safe to open anywhere, simple to reason about.
⚖ You switch to git / lazygit to act. ^pde0083

🏠 15. Local-only quality & release ^pde0087

🎯 No hosted CI, nothing auto-publishes.
✅ Full control; checks run on your machine and Docker.
⚖ Discipline needed: run make check before pushing. ^pde0088

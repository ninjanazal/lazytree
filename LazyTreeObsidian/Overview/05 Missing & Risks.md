worktree or submodule .git is a FILE → 'not inside a git
repository'. Bare repos fail too.

repository) ^p5x0014

Errors lose git's stderr ^p5x0016

128' with no reason.
Fix: wrap err with strings.TrimSpace(errOut.String()) ^p5x0018

show kills the session.
Fix: footer banner / toast; only first load is fatal ^p5x0022

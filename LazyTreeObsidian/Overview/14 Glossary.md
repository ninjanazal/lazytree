## Text Elements
📖 ^pgl0002

Glossary ^pgl0003

Plain-language explanations of the git, terminal and project terms used across this vault. ^pgl0004

🏠 Hub ^pgl0006

← Status & Risks ^pgl0008

Commit ^pgl0012

A saved snapshot of the project with a message, an
author and one or more parents. ^pgl0013

Parent ^pgl0017

The commit(s) a commit was built on. A merge has two
or more. ^pgl0018

Hash ^pgl0022

The commit's unique id (40 hex characters; lazytree
shows 7). ^pgl0023

Branch ^pgl0027

A movable name pointing at a commit (refs/heads/*). ^pgl0028

Remote branch ^pgl0032

Your copy of a branch on a server, e.g. origin/main
(refs/remotes/*). ^pgl0033

Tag ^pgl0037

A fixed name for a commit, usually a release
(refs/tags/*). ^pgl0038

HEAD ^pgl0042

The commit you have checked out; shown as HEAD ->
branch. ^pgl0043

Ref ^pgl0047

Any name for a commit: branch, remote branch, tag or
HEAD. ^pgl0048

Topology ^pgl0052

The shape of history: how commits fork and merge. ^pgl0053

Lane ^pgl0057

A column in the graph reserved for one line of
history. ^pgl0058

Connector row ^pgl0062

The extra ╰ ╮ row drawn when lanes fork or merge. ^pgl0063

Worktree / submodule / bare ^pgl0067

Other repository layouts git supports; lazytree finds
them all. ^pgl0068

Pickaxe (-S) ^pgl0072

git's search for commits that add or remove a piece
of text. ^pgl0073

TUI ^pgl0077

Terminal User Interface: an app drawn with text in
the terminal. ^pgl0078

Bubble Tea ^pgl0082

The Go TUI framework lazytree uses (Model · Update ·
View). ^pgl0083

Elm architecture ^pgl0087

State changes only in Update in reply to messages;
View just draws. ^pgl0088

tea.Cmd ^pgl0092

A function Bubble Tea runs in the background; its
result is a message. ^pgl0093

Lip Gloss ^pgl0097

Styling library: colours, borders, padding for
terminal text. ^pgl0098

AdaptiveColor ^pgl0102

A colour with light and dark variants, picked from
the terminal background. ^pgl0103

Debounce ^pgl0107

Wait until input stops (150 ms) before doing
expensive work. ^pgl0108

Seq / Gen token ^pgl0112

A counter attached to async work so stale results can
be ignored. ^pgl0113

Streaming ^pgl0117

Reading git's output bit by bit instead of all at
once. ^pgl0118

LRU cache ^pgl0122

Keeps the most recently used items (32 diffs), drops
the oldest. ^pgl0123

OSC 52 ^pgl0127

A terminal escape code that copies text to the
clipboard, even over SSH. ^pgl0128

vhs ^pgl0132

A tool that records terminal sessions to GIF/PNG from
a script (tape). ^pgl0133

goreleaser ^pgl0137

Builds release archives for every platform from one
config. ^pgl0138

Startup ^p3x0022

0), loadBranch, Tick 60s → FetchTick{1}, Tick 1s →

Why seqs are set in NewApp: Init has a value
receiver, so its changes to m are lost; only the
returned cmd survives ^p3x0029

Loading history (paging) ^p3x0032

loadCommitsCmd(0, gen)
git log [--all] --skip=0 --max-count=500
BuildRefsByHash → AttachRefs
graph.Layout(commits) ^p3x0034

MsgCommitsLoaded{Commits, Layout, Gen}
stale gen? drop · setCommits · if len==500 → next
page ^p3x0036

MsgCommitsBatch{Commits, Offset, Gen}
append · graph.Layout(ALL) ← full recompute
len==500 → next page, else loading=false ^p3x0039

⚠ refs re-read every page · --skip makes git re-walk
skipped history → cost grows with offset ^p3x0042

Diff on cursor move ^p3x0045

j/k moves cursor · Enter → popupOpen=true,
diffCmdIfChanged() ^p3x0047

scheduleDiffLoad(hash): debounceSeq++ · Tick(150ms) ^p3x0049

MsgDiffDebounce{Hash, Seq}
Seq current and still selected? → loadDiffCmd ^p3x0052

MsgDiffLoaded{Hash, Files}
still selected? → diff.setDiff ^p3x0055

Fast scrolling: old ticks fail the Seq check → only
the last position runs git show ^p3x0058

Live background fetch ^p3x0061

MsgFetchTick{Seq} every 60s
Seq current? → schedule next · if !fetchInFlight →
fetchCmd() ^p3x0063

MsgFetchResult{Err}
fetchInFlight=false ^p3x0065

Err == nil → reloadGen++ → loadCommits(0)
Err != nil → ignored, retry next tick ^p3x0068

⚠ reloads everything even when nothing changed;
compare for-each-ref first ^p3x0071

Stale-message guards ^p3x0074

Seq tokens (debounce / fetch / anim / countdown):
bump on reschedule; old Seq ignored → no duplicate
tick chains ^p3x0076

Gen token (reloadGen): bumped on 'a' toggle and after
fetch → pages from an older reload dropped ^p3x0078

Tick chains: FetchTick & CountdownTick live all
session · AnimationTick only in zen · spinner
internal ^p3x0080

Modes & key routing ^p3x0082

modeSearch → enter apply filter · esc clear · else
textinput ^p3x0084

q quit · esc close popup / leave zen · z zen (rebuild
+ anim chain; swallows other keys) ^p3x0086

popupOpen → scroll viewport · / search · a toggle
--all + reload · else move cursor, Enter opens popup ^p3x0088

⚠ Any MsgError → View() shows only 'Error: …' forever
(and stderr is dropped → 'exit status 128') ^p3x0090

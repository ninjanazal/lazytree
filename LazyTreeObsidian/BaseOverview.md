🔁 Runtime / message flow  ↗ ^te0036

Init()  → tea.Batch
spinner · loadCommits(0) · loadBranch
FetchTick(60s) · CountdownTick(1s) ^te0038

MsgCommitsLoaded (page 0 + Layout)
→ if len==pageSize: loadCommits(offset) ^te0040

MsgCommitsBatch  → append + FULL re-Layout
→ keep paging until short page ^te0042

cursor move → scheduleDiffLoad → MsgDiffDebounce{Seq}
→ still selected? → loadDiff → MsgDiffLoaded ^te0044

MsgFetchTick{Seq} (60s) → git fetch (30s timeout)
→ MsgFetchResult ok → reloadGen++ → reload page 0
→ error: swallowed silently, retry next tick ^te0046

MsgAnimationTick (120ms, only in zen)
MsgCountdownTick (1s, footer “next fetch in Ns”) ^te0048

Stale-message guards
• Seq tokens: debounce / fetch / anim / countdown chains
• Gen token: drops loads from superseded reloads
• Init uses value receiver → seqs pre-baked in NewApp ^te0050

Modes: modeLog · modeSearch · modeZen (+ popupOpen)

      z zen · esc back · q quit · enter (open) ^te0052

✅ Design choices  ↗ ^te0057

Graph layout decoupled from TUI → pure, testable ^te0059

Shell out to git CLI (no go-git): exact git semantics ^te0061

git log with NUL/SOH separators → safe multi-line bodies ^te0063

Async paging (pageSize) → UI never blocks ^te0065

Debounced diff loading on cursor move ^te0067

Silent live background fetch every 60s ^te0069

Seq / generation tokens instead of cancellation ^te0071

--all history by default, 'a' toggles to HEAD only ^te0073

In-memory search filter on loaded commits ^te0075

Refs mapped by full hash (tags dereferenced) ^te0077

Zen mode: ambient animated view of the repo ^te0079

🚧 What's missing / risks  ↗ ^te0081

✅ Repo root via git.ResolveRepo (rev-parse) → works in
worktrees, submodules & bare repos (fixed) ^te0083

✅ Runner.Run errors now include git's stderr (fixed) ^te0085

✅ graph.Layout is now incremental (Layouter) — batches
cost O(page) instead of O(total) (fixed) ^te0087

🟠 Diff: no syntax highlighting (README promises it);
DiffFile.Status, DiffLine.OldN/NewN never populated ^te0089

🟠 No commit inspector (metadata/parents/files) since
inspect pane was removed; README still lists it ^te0091

🟡 Dead code: FetchRefs, FetchChangedFiles, MsgSearchResult,
Enter/popup barely wired ^te0093

🟡 Search: substring only, no match highlight / n/N,
no git log --grep / -S / author filters ^te0095

🟡 No actions: copy hash, checkout, open in $EDITOR, blame ^te0097

🟡 No config (theme, keys, fetch interval), no help overlay ^te0099

🟡 Mouse enabled but unused; narrow-terminal layout unverified ^te0101

⚪ Tests: none for ui/app, ParseDiff, refs; no CI, no release
(goreleaser), README install path unverified ^te0103

🔴 Any MsgError replaces the whole UI with an error screen
(no way back, no retry) ^te0105

🟠 View() re-renders the full graph for ALL commits every frame

What is lazytree? ^phb0007

A terminal UI for exploring Git history. ^phb0010

It draws the real shape of a repository: every
branch as a coloured lane, merges as connectors,
refs as labels. Move the cursor and the selected
commit's details and syntax-highlighted diff
follow along on the right.

It is read-only: it never changes your repository.
Keyboard first, mouse friendly, fast on 100k+
commit repositories, readable in light and dark
terminals. ^phb0011
